# Fourfold attribution readiness

The completed preliminary report request is the supported conversion boundary:
`POST /api/leads` verifies the roof analysis, persists the lead, and returns the
report confirmation payload. The server hook runs after that save and sends a
best-effort Fourfold business event to `/api/conversions`.

The hook is disabled unless both `FOURFOLD_ATTRIBUTION_ENDPOINT` and
`FOURFOLD_ATTRIBUTION_SECRET` are configured. The endpoint must be a public
HTTPS Fourfold origin with `/api/conversions`; the secret is the source bearer
in Fourfold's `sourceId.secret` format. Its payload contains only:

- `eventId`, the database-generated opaque event ID;
- `occurredAt`, the save timestamp; and
- optional `attributionKey`, when the landing URL carries a valid Fourfold key.

It sends no name, email, phone, address, utility bill, report metrics, consent
text, raw referrer, or other lead fields. The attribution key must match
Fourfold's deterministic format `solarai-<platform>-<contentId>`, where
`platform` is `threads`, `instagram`, `facebook`, `youtube`, or `x`, and
`contentId` is the UUID generated by Fourfold for the published content.
Fourfold still performs the authoritative published-post and source check. Any
arbitrary, human-readable, cross-brand, or malformed `utm_id` is discarded
before the outbound request; it is not forwarded or hashed. The request uses
`redirect: "error"`, a short timeout, and returns a failure status without
changing the report response when the provider is unavailable.

The exact production blocker is external configuration: neither the Fourfold
endpoint nor a source bearer is configured in this repository. Until the owner
creates or selects the disabled Fourfold tracking source and supplies its
public HTTPS origin and bearer through the deployment environment, the hook
remains intentionally inactive. No Fourfold or other brand-repository files
were changed.

Public same-origin pages that can be used for organic discovery are:

- `https://solartelligence.com/`
- `https://solartelligence.com/solar-guide`
- `https://solartelligence.com/privacy`
- `https://solartelligence.com/terms`

The estimate, dashboard, report, and thank-you routes remain private or
noindex and are not listed in the sitemap.
