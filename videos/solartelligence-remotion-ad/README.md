# Solartelligence Facebook Ad

30-second, 1920x1080 Remotion composition for Facebook and Instagram feed placement.

## Run

From this directory:

```bash
npm install
npm run studio
npm run render
```

The current rerender is written to `out/solartelligence-facebook-ad-current.mp4`.

The address shown in the ad defaults to the Mesa test address `6420 E Nance St, Mesa, AZ 85215`. To rerender with another address in PowerShell:

```powershell
$env:AD_ADDRESS = "123 Example St, Mesa, AZ 85201"
npm run render
```

## Story

1. Look at the roof before calling an installer.
2. Enter one address.
3. Review satellite roof planes, panel layout, and sunlight quality.
4. Explore the same property in 3D.
5. Adjust bill and system assumptions to read the modeled report.
6. Finish with one clear `Analyze My Roof` CTA.

The 3D model now has a larger dedicated frame plus a short 3D-to-report transition so the roof geometry and module placement get more attention. The narration is pre-trimmed and concatenated into one continuous track to avoid dead air between scene clips.

The piece uses real Solartelligence capture assets and a muted-feed-safe voiceover/music bed. Preliminary estimate and installer-verification language remains on screen in the product beats and closing frame.
